# Poker Now HUD downloads

Versioned browser-extension packages for a small play-money pilot. Each release ZIP contains an unpacked Chrome Manifest V3 extension with `manifest.json` at its root. This repository contains downloads only; the development source repository remains private.

The extension runs on Poker Now game pages, keeps statistics and notes in your browser's local storage, and has no developer-operated server. It is independent of Poker Now and is not affiliated with its operator.

Follow the [download and installation guide](https://gist.github.com/alexlwn123/e4462c5bd1f6dd22ba9642cb6537bf84) to load a release ZIP in Chrome desktop. Updates are manual until a Chrome Web Store version is available.
